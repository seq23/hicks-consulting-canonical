GitHub connection

Checking configuration The buttons need a restricted GitHub connection to dispatch workflows.

  1. Create a fine-grained GitHub token restricted to seq23/hicks-consulting-canonical.
  2. Give it Actions: read/write and Contents: read/write. Do not grant access to other repositories.
  3. In Cloudflare Pages, open the Hicks project → Settings → Variables and Secrets. Add encrypted secrets GITHUB_ADMIN_TOKEN and GITHUB_REPOSITORY with value seq23/hicks-consulting-canonical.
  4. Redeploy once, then click Test GitHub connection. Until configured, buttons remain safely unavailable instead of returning an unexplained error.

Hicks Consulting

Hicks Consulting helps our clients heal beyond survival, break unhealthy cycles, and build healthier, more fulfilling lives through virtual therapy, coaching, consulting, and mental health support.

Through therapy, coaching, consulting, groups, and organizational training, Hicks Consulting supports clients of all ethnicities while bringing specialized care for Black women to the center of the practice.

This website is for informational purposes only and does not provide emergency or crisis services. Therapy services are virtual and limited to Tennessee. Coaching is not therapy and is not a substitute for mental health treatment.
